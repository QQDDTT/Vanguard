# 03. Agent 知识库规范 — Vanguard

## 1. 核心设计思想：为 Agent 优化
传统知识库服务于人类阅读（高上下文、长篇幅），Vanguard 知识库专门服务于 Agent 检索（原子化、高密度、结构化）。

## 2. 原子化知识条目结构

每一个知识条目必须满足以下约束：
- **篇幅控制**：单条字数控制在 200 - 500 字之间。
- **单一焦点**：仅描述一个核心现象、匹配信号与应对模式。
- **显式分类 (Category)**：
  - `INDUSTRY_BACKGROUND`：行业特点与业务背景
  - `CUSTOMER_PATTERN`：客户隐性动机与常见顾虑
  - `COMPETITOR_INSIGHT`：竞品优劣势对比与替换策略
  - `METHODOLOGY`：采访与引导技巧
  - `CASE_STUDY`：经典落地案例与沉淀

## 3. 示例格式

{
  "title": "B2B 决策者隐性顾虑：管理控制权丧失",

}
